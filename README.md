# Centro de Mando Redes

Panel privado con las estadísticas de YouTube, Instagram, Facebook y TikTok en un solo sitio.

- `index.html`: página única (HTML + CSS + JS vanilla). Se publica en GitHub Pages.
- `config.js`: URL del proyecto Supabase y anon key (pública; los datos los protege RLS).
- `supabase/migrations/`: esquema de la base de datos.
- `SKILL.md`: arquitectura, fases y reglas de trabajo del proyecto.
